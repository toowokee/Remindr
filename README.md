# Remindr

### Step 1. Git clone repository
```bash
git clone https://github.com/toowokee/Remindr
```

### Step 2. Change directory to cloned directory
```bash
cd Remindr
```

### Step 3. Install requirements
```bash
python3.10 -m pip install -r requirements.txt
```

### Step 4. Get a Discord bot token and enable intents from [HERE](https://discord.com/developers/applications)

#### Select [application](https://discord.com/developers/applications)

### Step 5. Rename `example.env` to `.env` and put your Discord bot token. It will look like this:
```env
DISCORD_TOKEN=YOUR_DISCORD_BOT_TOKEN
```

### Step 6. Run the bot
```bash
python3.10 main.py
```
